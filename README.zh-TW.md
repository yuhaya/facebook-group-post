# Facebook 社團發文（矩陣行銷）

> 一次設定，多個社團 × 多則文案 × 多個帳號指紋瀏覽器併發發文，放大社群觸達，減少重複貼上。

## 這個自動化能做什麼

這是給 **AutoAI 桌面用戶端** 使用的自動化專案。匯入後即可：

| 能力 | 你能得到什麼 |
|---|---|
| **Facebook 社團發文** | 開啟社團主頁，發布「文案 + 圖片」或「文案 + 單一影片」 |
| **矩陣放大** | 貼上多個社團連結 + 多則文案 → **每個社團都會發一遍全部文案**（任務數 = 社團數 × 文案數） |
| **多帳號瀏覽器** | 產生的任務依所选指紋瀏覽器 **輪詢均分**——一瀏覽器一帳號，自然分流 |
| **素材池** | 圖片池依「每帖張數」取圖並循環；影片池每帖 1 個並循環 |
| **可選匿名** | 若發文彈窗有「匿名發文」開關，可自動開啟 |
| **擬人排程** | 每日上限、發文間隔隨機區間、每日時間窗（支援跨日，例如本地夜間對齊美國白天） |

### 為什麼強調「矩陣發文」

人工社團行銷難以規模化：一個人、一個帳號、一個社團慢慢貼。

用本專案可以例如：

- **20 個社團 × 5 則文案 = 100 條任務**，再分到多台指紋瀏覽器排程執行  
- 同一產品用多套文案／素材覆蓋不同社群，減少機械複製  
- 用跨日時間窗，讓貼文落在目標受眾在線時段  

**正式跑任務組幾乎不消耗 AI 算力（Token）。** 算力主要用於智能體開發、適配與排錯（見下方「需要客製怎麼辦」）。

> 請僅對自有或已獲授權的帳號與社團使用，並遵守 Facebook 規則與當地法規。

## 使用前提

- **AutoAI 桌面用戶端**（[下載](https://www.xrobot.tech/zh-TW/download/)）
  - **Windows：** 僅 x86 / x64（不支援 ARM）
  - **macOS：** 僅 Apple 晶片 M 系列（不支援 Intel Mac）
- AutoAI 帳戶（[註冊](https://www.xrobot.tech/zh-TW/register/) · [登入](https://www.xrobot.tech/zh-TW/login/)）
- 用戶端內至少一台 **指紋瀏覽器**，且已手動登入 Facebook
- **裝置額度：** AutoAI **預設贈送 1 個免費指紋瀏覽器環境**；做矩陣／多帳號時，可依需求在用戶端或 [帳戶中心](https://www.xrobot.tech/zh-TW/account/) **購買更多指紋瀏覽器環境**

## 客戶上手路徑

### 1. 下載用戶端

開啟下載頁，依系統安裝：

👉 [https://www.xrobot.tech/zh-TW/download/](https://www.xrobot.tech/zh-TW/download/)

（簡體下載頁亦可：[https://www.xrobot.tech/zh/download/](https://www.xrobot.tech/zh/download/)）

### 2. 註冊並登入

1. 開啟 [註冊頁](https://www.xrobot.tech/zh-TW/register/)，用電子郵件完成註冊（驗證碼／密碼）。
2. 可在官網 [登入](https://www.xrobot.tech/zh-TW/login/)；**必須在桌面用戶端用同一帳號登入**。

### 3. 準備 Facebook 指紋瀏覽器

AutoAI **預設自帶 1 個免費指紋環境**（**平台瀏覽器**），足夠先跑通單一帳號。矩陣發文更適合 **多瀏覽器（多帳號）**：額度不夠時，依自己的帳號數量 **購買更多指紋瀏覽器環境**，再建立對應瀏覽器。

1. 用戶端左側進入 **瀏覽器**。
2. 優先選 **平台瀏覽器**（內建免費指紋環境）；也可使用比特瀏覽器／AdsPower（需本機已啟動對應軟體）。
3. **建立瀏覽器** → **啟動** → 需要看畫面時開啟 **投屏**。
4. 在該瀏覽器裡 **手動登入 Facebook**，確認工作階段正常後再建任務。
5. 需要更多帳號時：購買額外指紋環境額度 → 再建立多個瀏覽器 → 各自登入 Facebook → 建任務組時一併勾選。

### 4. 從 GitHub 匯入本專案

1. 開啟 **自動化 → 匯入**（或用戶端中的「從 GitHub 匯入」入口）。
2. 貼上倉庫位址：`https://github.com/yuhaya/facebook-group-post`（也可填 `yuhaya/facebook-group-post` 或 `git@github.com:yuhaya/facebook-group-post.git`）。
3. 確認資訊後點擊 **開始匯入**。
4. 匯入成功後，專案出現在 **自動化 → 我的自動化**。

### 5. 建立任務組（矩陣執行）

1. 開啟 **自動化 → 我的自動化**。
2. **點擊專案卡片主體**（不要點底部「××自動化專家」按鈕）。
3. 填寫表單，例如：
   - **社團主頁連結**：每行一個 Facebook 社團 URL  
   - **貼文文案列表**：多則文案用 `==sep==` 分隔（單則內可以換行）  
   - **瀏覽器**：勾選一台或多台已登入的指紋瀏覽器  
   - **附件**：圖片（及每帖張數）或影片  
   - **頻率**：每日上限、間隔上下限、每日時間窗  
4. 點 **建立** → 核對計劃時間與任務量 → 確認提交。
5. 若提示開啟任務總開關，請打開右上角 **任務**，否則排隊任務不會執行。
6. 在 **任務組管理** 查看進度與結果。

**任務數量規則：**  
`社團數 × 文案數`（沒有文案時仍可發純圖／純影片，相當於 1 則空文案）。產生後的任務再依所选瀏覽器 **輪詢均分**。

## 表單欄位速查

| 欄位 | 含義 |
|---|---|
| 社團主頁連結 | 每行一個 URL；每個社團都會發一遍全部文案 |
| 貼文文案列表 | 用 `==sep==` 分隔；每個社團發全部文案 |
| 匿名發文 | 開啟後：彈窗有匿名開關則自動打開 |
| 附件類型 | 圖片（可多張）或影片（每帖 1 個） |
| 圖片／影片 | 素材池；依序取用，用完後循環 |
| 每帖圖片張數 | 每條任務從圖片池取幾張 |
| 瀏覽器 | 實際執行發文的指紋環境 |
| 每日上限 | 每台瀏覽器、每個時間窗日內最多發多少條 |
| 間隔最小／最大 | 兩條任務之間的隨機等待（秒） |
| 每日開始／結束 | 允許發文時段；**開始時間晚於結束** 表示跨日（如 `22:00` → `06:00`） |

## 需要客製怎麼辦

官方案例與你的介面語言、帳號類型、地區、社團規則可能不一致——用用戶端內建智能體適配即可。

### 先儲值算力（智能體對話需要）

正式批次跑任務幾乎不燒 Token；**找智能體改需求／排錯** 才會消耗 **AI 算力**。

1. 在官網帳戶中心 **儲值美元餘額**。  
2. 開啟桌面用戶端 → 個人中心／錢包 → **購買 AI 算力**。  
3. 算力到帳後再開智能體對話。

若用戶端提示「對話需要算力」，依介面引導：儲值餘額 → 購買算力。

### 用智能體改這個專案

**A. 改功能／適配你的環境（開發模式）**

1. 在 **我的自動化** 卡片底部，點擊 **瀏覽器自動化專家**。  
2. 依提示選擇一台已 **啟動** 的除錯瀏覽器。  
3. 用自然語言說明需求，例如：
   - 「只在已加入的社團發文，遇到加入門檻就跳過。」
   - 「依星期輪換兩套素材。」
   - 「匯入後第 X 步失敗，請結合投屏排查並試跑修復。」
4. 改完讓智能體 **試跑腳本**，再回到「我的自動化」新建任務組。

**B. 針對某次失敗的任務組（排錯模式）**

1. **自動化 → 任務組管理**  
2. 在失敗任務組上使用 **排查並修復**  
3. 智能體會依該組失敗原因修復

## 矩陣效果小建議

- 優先 **多瀏覽器（多帳號）**，避免單號高頻刷屏。可先用 **免費的 1 個** 環境試跑；矩陣放大時再依需求購買更多指紋瀏覽器。  
- 間隔與每日上限留餘量；跨日視窗適合覆蓋海外白天。  
- 文案與素材要有差異，減少同質刷帖風險。  
- 大批量建組前，確認每台瀏覽器已登入 Facebook。  
- 正式跑任務 ≈ **0 Token**；算力留給客製與排錯。
