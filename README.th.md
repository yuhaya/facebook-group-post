## ระบบอัตโนมัตินี้ทำอะไรได้

โปรเจกต์สำหรับไคลเอนต์เดสก์ท็อป **AutoAI** หลังนำเข้า:

| ความสามารถ | ผลลัพธ์ |
|---|---|
| **โพสต์กลุ่ม Facebook** | เปิดกลุ่มแล้วโพสต์ข้อความ+รูป หรือข้อความ+วิดีโอ 1 คลิป |
| **ขยายแบบเมทริกซ์** | หลาย URL + หลายข้อความ → **ทุกกลุ่มได้ทุกข้อความ** (งาน = กลุ่ม × ข้อความ) |
| **หลายเบราว์เซอร์/บัญชี** | งานแจกแบบ **round-robin** ตาม fingerprint ที่เลือก (1 เบราว์เซอร์ = 1 บัญชี) |
| **คลังมีเดีย** | คลังรูป (N ต่อโพสต์ วนซ้ำ) หรือวิดีโอ (1 ต่อโพสต์) |
| **โพสต์ไม่ระบุชื่อ (เลือกได้)** | เปิดสวิตช์ถ้ามีในกล่องสร้างโพสต์ |
| **ตารางเวลาเหมือนคนจริง** | จำกัดรายวัน ช่วงสุ่ม หน้าต่างเวลา (รองรับข้ามคืน) |

### ทำไมต้อง “เมทริกซ์”

การตลาดกลุ่มด้วยมือขยายยาก

ตัวอย่าง:

- **20 กลุ่ม × 5 ข้อความ = 100 งาน** จัดตารางบนหลายเบราว์เซอร์  
- ข้อเสนอเดียวกันด้วยข้อความ/มีเดียต่างกันในหลายชุมชน  
- หน้าต่างข้ามคืนเพื่อโพสต์ตอนผู้ชมออนไลน์  

**การรัน production แทบไม่กินโทเคน AI** โทเคนใช้หลัก ๆ กับพัฒนา / ปรับ / ซ่อมผ่านเอเจนต์

> ใช้เฉพาะบัญชี/กลุ่มที่คุณเป็นเจ้าของหรือได้รับอนุญาต ปฏิบัติตามกฎ Facebook และกฎหมายท้องถิ่น

## เริ่มต้นเร็ว

### 1. ดาวน์โหลดไคลเอนต์

👉 [https://www.xrobot.tech/th/download/](https://www.xrobot.tech/th/download/)

### 2. สมัครและเข้าสู่ระบบ

1. [สมัคร](https://www.xrobot.tech/th/register/) (อีเมล + รหัสยืนยัน / รหัสผ่าน)
2. เข้าสู่ระบบเว็บได้ตามต้องการ **ต้องเข้าสู่ระบบด้วยบัญชีเดียวกันในไคลเอนต์เดสก์ท็อป**

### 3. เตรียมเบราว์เซอร์ Facebook

AutoAI มี **สภาพแวดล้อมลายนิ้วมือฟรี 1 อัน** (**เบราว์เซอร์แพลตฟอร์ม**) เพียงพอสำหรับบัญชีเดียว เมทริกซ์ดีกว่าด้วย **หลายเบราว์เซอร์ (หลายบัญชี)** — ซื้อโควตาและสร้างสภาพแวดล้อมเพิ่มตามต้องการ

1. แถบข้าง **เบราว์เซอร์**
2. เลือก **เบราว์เซอร์แพลตฟอร์ม** (ฟรีในตัว) เป็นหลัก; BitBrowser / AdsPower ก็ได้
3. **สร้าง** → **เริ่ม** → เปิด **Cast** หากต้องการดูหน้าจอ
4. **ล็อกอิน Facebook ด้วยมือ**
5. บัญชีเพิ่ม: ซื้อโควตา → สร้างเบราว์เซอร์ → ล็อกอินทีละตัว → เลือกทั้งหมดตอนสร้างกลุ่มงาน

### 4. นำเข้าจาก GitHub

1. **ระบบอัตโนมัติ → นำเข้า**
2. วางที่อยู่รีโป: `https://github.com/yuhaya/facebook-group-post` (หรือ `yuhaya/facebook-group-post` / `git@github.com:yuhaya/facebook-group-post.git`)
3. **เริ่มนำเข้า**
4. ปรากฏใน **ระบบอัตโนมัติ → ระบบอัตโนมัติของฉัน**

### 5. สร้างกลุ่มงาน (รันเมทริกซ์)

1. **ระบบอัตโนมัติของฉัน**
2. **คลิกตัวการ์ด** (ไม่ใช่ปุ่มผู้เชี่ยวชาญด้านล่าง)
3. URL กลุ่ม ข้อความ (`==sep==`) เบราว์เซอร์ มีเดีย ตารางเวลา
4. **สร้าง** → ตรวจเวลาและจำนวน
5. เปิดสวิตช์หลัก **งาน** มุมขวาบนหากถูกถาม
6. ติดตามใน **จัดการกลุ่มงาน**

**กฎ:** `จำนวนกลุ่ม × จำนวนข้อความ` จากนั้น round-robin ตามเบราว์เซอร์

## ช่องฟอร์ม

| ช่อง | ความหมาย |
|---|---|
| URL กลุ่ม | หนึ่ง URL ต่อบรรทัด; ทุกกลุ่มได้ทุกข้อความ |
| ข้อความ | แยกด้วย `==sep==` |
| โพสต์ไม่ระบุชื่อ | เปิด → เปิดสวิตช์ถ้ามี |
| ประเภทมีเดีย | รูป (หลาย) / วิดีโอ (หนึ่งต่อโพสต์) |
| รูป / วิดีโอ | คลังตามลำดับแล้ววน |
| รูปต่อโพสต์ | กี่รูปจากคลัง |
| เบราว์เซอร์ | สภาพแวดล้อมลายนิ้วมือที่รัน |
| จำกัดรายวัน | สูงสุดต่อเบราว์เซอร์ในหน้าต่าง |
| ช่วง min / max | รอสุ่ม (วินาที) |
| เริ่ม / จบรายวัน | **เริ่ม > จบ** = ข้ามคืน (เช่น `22:00`→`06:00`) |
