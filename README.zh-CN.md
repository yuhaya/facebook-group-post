# Facebook 小组发帖（矩阵营销）

> 一次配置，多个小组 × 多条文案 × 多个账号指纹浏览器并发发帖，放大社群触达，少做重复粘贴。

**语言：** [English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [ไทย](README.th.md) · [Bahasa Indonesia](README.id.md) · [Bahasa Melayu](README.ms.md) · [Tiếng Việt](README.vi.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Português](README.pt-BR.md) · [Français](README.fr.md) · [Русский](README.ru.md)

## 这个自动化能做什么

这是一份给 **AutoAI 桌面客户端** 使用的自动化项目。导入后即可：

| 能力 | 你能得到什么 |
|---|---|
| **Facebook 小组发帖** | 打开小组主页，发布「文案 + 图片」或「文案 + 单个视频」 |
| **矩阵放大** | 粘贴多个小组链接 + 多条文案 → **每个小组都会发一遍全部文案**（任务数 = 小组数 × 文案数） |
| **多账号浏览器** | 生成的任务按所选指纹浏览器 **轮询均分**——一浏览器一账号，自然分流 |
| **素材池** | 图片池按「每帖张数」取图并循环；视频池每帖 1 个并循环 |
| **可选匿名** | 若发帖弹窗有「匿名发帖」开关，可自动打开 |
| **拟人排程** | 每日上限、发帖间隔随机区间、每日时间窗（支持跨天，例如国内夜间对齐美国白天） |

### 为什么强调「矩阵发帖」

人工小组营销难规模化：一个人、一个号、一个组慢慢贴。

用本项目可以例如：

- **20 个小组 × 5 条文案 = 100 条任务**，再分到多台指纹浏览器排程执行  
- 同一产品用多套文案 / 素材覆盖不同社群，减少机械复制  
- 用跨天时间窗，让帖子落在目标受众在线时段  

**正式跑任务组几乎不消耗 AI 算力（Token）。** 算力主要用于智能体开发、适配与排错（见下方「需要定制怎么办」）。

> 请仅对自有或已获授权的账号与小组使用，并遵守 Facebook 规则与当地法规。

## 使用前提

- **AutoAI 桌面客户端**（[下载](https://www.xrobot.tech/zh/download/)）
  - **Windows：** 仅 x86 / x64（不支持 ARM）
  - **macOS：** 仅 Apple 芯片 M 系列（不支持 Intel Mac）
- AutoAI 账户（[注册](https://www.xrobot.tech/zh/register/) · [登录](https://www.xrobot.tech/zh/login/)）
- 客户端内至少一台 **指纹浏览器**，且已手动登录 Facebook
- **设备额度：** AutoAI **默认赠送 1 个免费指纹浏览器环境**；做矩阵 / 多账号时，可按需在客户端或 [账户中心](https://www.xrobot.tech/zh/account/) **购买更多指纹浏览器环境**

## 客户上手路径

### 1. 下载客户端

打开下载页，按系统安装：

👉 [https://www.xrobot.tech/zh/download/](https://www.xrobot.tech/zh/download/)

### 2. 注册并登录

1. 打开 [注册页](https://www.xrobot.tech/zh/register/)，用邮箱完成注册（验证码 / 密码）。
2. 可在官网 [登录](https://www.xrobot.tech/zh/login/)；**必须在桌面客户端用同一账号登录**。

### 3. 准备 Facebook 指纹浏览器

AutoAI **默认自带 1 个免费指纹环境**（**平台浏览器**），足够先跑通单个账号。矩阵发帖更适合 **多浏览器（多账号）**：额度不够时，按自己的账号数量 **购买更多指纹浏览器环境**，再创建对应浏览器。

1. 客户端左侧进入 **浏览器**。
2. 优先选 **平台浏览器**（内置免费指纹环境）；也可使用比特浏览器 / AdsPower（需本机已启动对应软件）。
3. **创建浏览器** → **启动** → 需要看画面时打开 **投屏**。
4. 在该浏览器里 **手动登录 Facebook**，确认会话正常后再建任务。
5. 需要更多账号时：购买额外指纹环境额度 → 再创建多个浏览器 → 各自登录 Facebook → 建任务组时一并勾选。

### 4. 从 GitHub 导入本项目

1. 打开 **自动化 → 导入**（或客户端中的「从 GitHub 导入」入口）。
2. 粘贴仓库地址：`https://github.com/yuhaya/facebook-group-post`（也可填 `yuhaya/facebook-group-post` 或 `git@github.com:yuhaya/facebook-group-post.git`）。
3. 确认信息后点击 **开始导入**。
4. 导入成功后，项目出现在 **自动化 → 我的自动化**。

### 5. 创建任务组（矩阵执行）

1. 打开 **自动化 → 我的自动化**。
2. **点击项目卡片主体**（不要点底部「××自动化专家」按钮）。
3. 填写表单，例如：
   - **小组主页链接**：每行一个 Facebook 小组 URL  
   - **帖子文案列表**：多条文案用 `==sep==` 分隔（单条内可以换行）  
   - **浏览器**：勾选一台或多台已登录的指纹浏览器  
   - **附件**：图片（及每帖张数）或视频  
   - **频率**：每日上限、间隔上下限、每日时间窗  
4. 点 **创建** → 核对计划时间与任务量 → 确认提交。
5. 若提示开启任务总开关，请打开右上角 **任务**，否则排队任务不会执行。
6. 在 **任务组管理** 查看进度与结果。

**任务数量规则：**  
`小组数 × 文案数`（没有文案时仍可发纯图/纯视频，相当于 1 条空文案）。生成后的任务再按所选浏览器 **轮询均分**。

## 表单字段速查

| 字段 | 含义 |
|---|---|
| 小组主页链接 | 每行一个 URL；每个小组都会发一遍全部文案 |
| 帖子文案列表 | 用 `==sep==` 分隔；每个小组发全部文案 |
| 匿名发帖 | 开启后：弹窗有匿名开关则自动打开 |
| 附件类型 | 图片（可多张）或视频（每帖 1 个） |
| 图片 / 视频 | 素材池；按顺序取用，用完后循环 |
| 每帖图片张数 | 每条任务从图片池取几张 |
| 浏览器 | 实际执行发帖的指纹环境 |
| 每日上限 | 每台浏览器、每个时间窗日内最多发多少条 |
| 间隔最小 / 最大 | 两条任务之间的随机等待（秒） |
| 每日开始 / 结束 | 允许发帖时段；**开始时间晚于结束** 表示跨天（如 `22:00` → `06:00`） |

## 需要定制怎么办

官方案例与你的界面语言、账号类型、地区、小组规则可能不一致——用客户端内置智能体适配即可。

### 先充值算力（智能体对话需要）

正式批量跑任务几乎不烧 Token；**找智能体改需求 / 排错** 才会消耗 **AI 算力**。

1. 在官网账户中心 **充值美元余额**。  
2. 打开桌面客户端 → 个人中心 / 钱包 → **购买 AI 算力**。  
3. 算力到账后再开智能体对话。

若客户端提示「对话需要算力」，按界面引导：充值余额 → 购买算力。

### 用智能体改这个项目

**A. 改功能 / 适配你的环境（开发模式）**

1. 在 **我的自动化** 卡片底部，点击 **浏览器自动化专家**。  
2. 按提示选择一台已 **启动** 的调试浏览器。  
3. 用自然语言说明需求，例如：
   - 「只在已加入的小组发帖，遇到加入门槛就跳过。」
   - 「按星期轮换两套素材。」
   - 「导入后第 X 步失败，请结合投屏排查并试跑修复。」
4. 改完让智能体 **试跑脚本**，再回到「我的自动化」新建任务组。

**B. 针对某次失败的任务组（排错模式）**

1. **自动化 → 任务组管理**  
2. 在失败任务组上使用 **排查并修复**  
3. 智能体会按该组失败原因修复

## 矩阵效果小建议

- 优先 **多浏览器（多账号）**，避免单号高频刷屏。可先用 **免费的 1 个** 环境试跑；矩阵放大时再按需购买更多指纹浏览器。  
- 间隔与每日上限留余量；跨天窗口适合覆盖海外白天。  
- 文案与素材要有差异，减少同质刷帖风险。  
- 大批量建组前，确认每台浏览器已登录 Facebook。  
- 正式跑任务 ≈ **0 Token**；算力留给定制与排错。
