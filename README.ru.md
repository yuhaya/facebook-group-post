## Что делает эта автоматизация

Проект для десктоп-клиента **AutoAI**. После импорта:

| Возможность | Результат |
|---|---|
| **Посты в группах Facebook** | Открыть группу и опубликовать текст + изображения или текст + одно видео |
| **Матричное масштабирование** | Много URL + много текстов → **каждая группа получает все тексты** (задачи = группы × тексты) |
| **Несколько браузеров/аккаунтов** | Задачи распределяются **round-robin** по выбранным fingerprint (1 браузер = 1 аккаунт) |
| **Пулы медиа** | Пул изображений (N на пост, по кругу) или видео (1 на пост) |
| **Анонимно (опционально)** | Включает «Анонимный пост», если переключатель есть |
| **«Живое» расписание** | Дневной лимит, случайный интервал, окно времени (возможен ночной переход) |

### Зачем «матрица»

Ручной маркетинг в группах плохо масштабируется.

Примеры:

- **20 групп × 5 текстов = 100 задач**, по нескольким браузерам  
- Одно предложение с разными текстами/медиа в разных сообществах  
- Ночные окна, чтобы пост попал в онлайн аудитории  

**Продакшен-запуски почти не тратят AI-токены.** Токены нужны в основном для разработки, адаптации и починки через агента.

> Используйте только свои или авторизованные аккаунты/группы. Соблюдайте правила Facebook и местный закон.

## Быстрый старт

### 1. Скачать клиент

👉 [https://www.xrobot.tech/ru/download/](https://www.xrobot.tech/ru/download/)

### 2. Регистрация и вход

1. [Регистрация](https://www.xrobot.tech/ru/register/) (email + код / пароль).
2. Вход на сайте опционален. **В десктоп-клиенте войдите тем же аккаунтом.**

### 3. Подготовить Facebook-браузер

В AutoAI есть **одна бесплатная fingerprint-среда** (**Платформенный браузер**). Хватает для одного аккаунта. Матрица лучше с **несколькими браузерами (аккаунтами)** — купите квоту и создайте среды по необходимости.

1. Боковая панель **Браузер**.
2. Предпочтительно **Платформенный браузер** (бесплатный встроенный); BitBrowser / AdsPower тоже можно.
3. **Создать** → **Запуск** → при необходимости **Cast**.
4. **Вручную войдите в Facebook**.
5. Больше аккаунтов: купить квоту → создать браузеры → логин в каждом → выбрать все при создании группы задач.

### 4. Импорт с GitHub

1. **Автоматизация → Импорт**.
2. Вставьте: `https://github.com/yuhaya/facebook-group-post` (также `yuhaya/facebook-group-post` или `git@github.com:yuhaya/facebook-group-post.git`).
3. **Начать импорт**.
4. Проект появится в **Автоматизация → Мои автоматизации**.

### 5. Создать группу задач (матричный запуск)

1. **Мои автоматизации**.
2. **Клик по телу карточки** (не кнопка эксперта внизу).
3. URL групп, тексты (`==sep==`), браузеры, медиа, расписание.
4. **Создать** → проверить время и количество.
5. При запросе включите главный переключатель **Задачи** справа сверху.
6. Смотрите прогресс в **Управление группами задач**.

**Правило:** `группы × тексты`. Затем round-robin по браузерам.

## Поля формы

| Поле | Смысл |
|---|---|
| URL групп | Один URL на строку; каждая группа получает все тексты |
| Тексты | Разделитель `==sep==` |
| Анонимный пост | Вкл. → включить переключатель, если есть |
| Тип медиа | Изображения (несколько) / Видео (одно на пост) |
| Изображения / Видео | Пул по порядку, затем по кругу |
| Изображений на пост | Сколько из пула |
| Браузеры | Fingerprint-среды исполнения |
| Дневной лимит | Макс. на браузер в окне |
| Интервал min / max | Случайная пауза (секунды) |
| Начало / конец дня | **начало > конец** = ночной переход (напр. `22:00`→`06:00`) |

## Советы

- Лучше **несколько браузеров (аккаунтов)**. Начните с **бесплатного**; при росте купите fingerprint-слоты.  
- Интервалы и лимиты с запасом; ночные окна — для дневного времени за рубежом.  
- Варьируйте тексты и медиа.  
- Перед большими пакетами проверьте логин Facebook.  
- Продакшен ≈ **0 токенов**.
