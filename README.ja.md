# Facebook グループ投稿（マトリクス配信）

> 一度の設定で、複数グループ × 複数キャプション × 複数アカウントの指紋ブラウザから同時投稿。リーチを広げ、手作業のコピペを減らします。

## この自動化でできること

**AutoAI** デスクトップ向けの自動化プロジェクトです。クライアントにインポートすると：

| 機能 | 得られること |
|---|---|
| **Facebook グループ投稿** | グループページを開き、キャプション＋画像、またはキャプション＋動画1本を投稿 |
| **マトリクス拡大** | 複数のグループ URL と複数の文案 → **各グループがすべての文案を投稿**（タスク数 = グループ数 × 文案数） |
| **マルチアカウントブラウザ** | 選んだ指紋ブラウザへタスクを **ラウンドロビン** 配分（ブラウザ1つ＝アカウント1つ） |
| **メディアプール** | 画像プール（1投稿あたり N 枚・循環）／動画プール（1投稿1本・循環） |
| **匿名投稿（任意）** | 作曲ダイアログに「匿名で投稿」があれば自動でオン |
| **人らしいスケジュール** | 日次上限、投稿間隔の乱数、日次時間帯（深夜跨ぎ可。例：現地夜＝米国昼） |

### なぜ「マトリクス投稿」か

人手のグループマーケはスケールしません。1人・1アカウント・1グループずつでは限界があります。

例：

- **20 グループ × 5 文案 = 100 タスク** を複数ブラウザに分散スケジュール  
- 同じオファーを文案・素材を変えて複数コミュニティへ  
- 深夜跨ぎウィンドウで、オーディエンスがオンラインの時間に投稿  

**本番のタスクグループ実行はほぼ AI トークンを消費しません。** トークンは主にエージェントでの開発・適応・修復に使います（下記「カスタマイズ」参照）。

> 所有または権限のあるアカウント／グループのみ使用し、Facebook の規約と現地法を守ってください。

## 前提条件

- **AutoAI デスクトップクライアント**（[ダウンロード](https://www.xrobot.tech/ja/download/)）
  - **Windows:** x86 / x64 のみ（ARM 非対応）
  - **macOS:** Apple シリコン（M シリーズ）のみ（Intel Mac 非対応）
- AutoAI アカウント（[登録](https://www.xrobot.tech/ja/register/) · [ログイン](https://www.xrobot.tech/ja/login/)）
- クライアント内に Facebook ログイン済みの **指紋ブラウザ** が1つ以上
- **枠数:** AutoAI は **無料の指紋ブラウザ環境を1つ** 付与。マトリクス／複数アカウント時は、必要に応じてクライアントまたは [アカウント](https://www.xrobot.tech/ja/account/) で **追加購入**

## クイックスタート

### 1. クライアントをダウンロード

👉 [https://www.xrobot.tech/ja/download/](https://www.xrobot.tech/ja/download/)

### 2. 登録とログイン

1. [登録](https://www.xrobot.tech/ja/register/)（メール＋認証コード／パスワード）。
2. サイトで [ログイン](https://www.xrobot.tech/ja/login/) も可。**デスクトップクライアントでも同じアカウントでログイン必須**。

### 3. Facebook 用指紋ブラウザを用意

AutoAI には **無料の指紋環境が1つ**（**プラットフォームブラウザ**）付属。まず1アカウントの動作確認に十分です。マトリクスは **複数ブラウザ（複数アカウント）** が向いています。足りなければ枠を購入して環境を増やしてください。

1. 左サイドバーで **ブラウザ** を開く。
2. **プラットフォームブラウザ**（内蔵無料）を推奨。BitBrowser / AdsPower も可（該当アプリ起動済みであること）。
3. **作成** → **起動** → 必要なら **キャスト** をオン。
4. そのブラウザで **Facebook に手動ログイン**し、セッションを確認。
5. アカウントを増やす場合：枠を購入 → ブラウザを追加作成 → それぞれ Facebook ログイン → タスクグループ作成時にまとめて選択。

### 4. GitHub からインポート

1. **自動化 → インポート**（または「GitHub からインポート」）。
2. リポジトリ URL を貼り付け：`https://github.com/yuhaya/facebook-group-post`（`yuhaya/facebook-group-post` または `git@github.com:yuhaya/facebook-group-post.git` も可）。
3. 確認して **インポート開始**。
4. **自動化 → マイ自動化** に表示されます。

### 5. タスクグループ作成（マトリクス実行）

1. **自動化 → マイ自動化**。
2. **カード本体をクリック**（下部のエキスパートボタンではない）。
3. 例：
   - **グループ URL** — 1行に1つ  
   - **キャプション** — `==sep==` で区切る（1件内の改行可）  
   - **ブラウザ** — ログイン済み指紋ブラウザを選択  
   - **メディア** — 画像（枚数）または動画  
   - **スケジュール** — 日次上限・間隔・時間帯  
4. **作成** → 予定時刻と件数を確認 → 送信。
5. 求められたら右上の **タスク** マスタースイッチをオン。
6. **タスクグループ管理** で進捗を確認。

**タスク数:** `グループ数 × 文案数`（文案なしでもメディアのみ投稿可＝空文案1件扱い）。生成後は選択ブラウザへ **ラウンドロビン**。

## フォーム項目

| 項目 | 意味 |
|---|---|
| グループ URL | 1行1 URL。各グループが全キャプションを投稿 |
| キャプション | `==sep==` で区切り。各グループが全文案を投稿 |
| 匿名投稿 | オン時、作曲 UI にスイッチがあれば有効化 |
| メディア種別 | 画像（複数可）／動画（1投稿1本） |
| 画像／動画 | プール。順番に使用し尽きたら循環 |
| 投稿あたり画像数 | プールから何枚取るか |
| ブラウザ | 投稿を実行する指紋環境 |
| 日次上限 | 時間帯内・ブラウザあたりの上限 |
| 間隔 min / max | 投稿間のランダム待機（秒） |
| 日次開始／終了 | 許可時間帯。**開始 > 終了** は深夜跨ぎ（例 `22:00`→`06:00`） |

## カスタマイズが必要なとき

公式スクリプトと UI 言語・アカウント種別・地域が違うのは普通です。内蔵エージェントで合わせてください。

### まず計算リソースをチャージ（エージェント会話用）

本番バッチはほぼ Token を使いません。**エージェントでの改修／トラブルシュート** が **AI 計算リソース** を消費します。

1. サイトのアカウントで **USD 残高をチャージ**。  
2. デスクトップ → プロフィール／ウォレット → **AI 計算を購入**。  
3. 反映後にエージェント会話を開始。

### エージェントに依頼

**A. 機能変更／環境適応（開発モード）**

1. **マイ自動化** カード下部の **ブラウザ自動化エキスパート**。  
2. **起動済み** デバッグブラウザを選択。  
3. 自然言語で要望（例：「参加済みグループのみ投稿」「曜日で素材ローテ」「手順 X が失敗、キャストで修正して試行実行」）。  
4. **スクリプト試行** 後、カードから新しいタスクグループを作成。

**B. 失敗したバッチ（トラブルシュートモード）**

1. **自動化 → タスクグループ管理**  
2. 失敗グループで **調査して修復**

## マトリクスのコツ

- **複数ブラウザ（複数アカウント）** を優先。まず **無料1枠** で試し、拡大時に指紋枠を追加購入。  
- 間隔と日次上限に余裕を。深夜跨ぎは海外の昼間に有効。  
- 文案・素材を変え、同一スパムを避ける。  
- 大量作成前に各ブラウザの Facebook ログインを確認。  
- 本番 ≈ **0 Token**。計算リソースはカスタムと修復用に。
